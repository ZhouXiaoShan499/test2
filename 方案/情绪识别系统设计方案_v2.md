# MindBloom 情绪识别系统设计方案（行为模式推断版）

## 一、项目概述

### 1.1 项目背景
MindBloom 是一个情绪记录与反思工具，但存在"情绪无意识"的痛点——用户往往没有意识到自己的情绪状态。本系统通过**无感采集设备交互行为数据**，间接推断用户的情绪状态，实现被动式情绪觉察。

### 1.2 核心价值主张
- **无感觉察**：无需用户主动报告，静默分析行为模式
- **情绪标签化**：将模糊的情绪感受转化为可管理的 MindBloom 标签
- **反思引导**：基于情绪状态提供 AI 反思问题，帮助用户深入思考
- **隐私优先**：所有数据本地存储，符合 GDPR 标准

### 1.3 核心目标
- **行为 → 情绪推断**：从鼠标/键盘/应用使用模式推断情绪状态
- **情绪 → 标签映射**：将推断的情绪映射到 MindBloom 情绪标签体系
- **情绪 → 反思引导**：为每个情绪状态提供针对性的反思问题
- **情绪 → 视觉呈现**：在 MindBloom 中生成视觉化情绪卡片

## 二、情绪 - 行为模式映射体系

### 2.1 核心原理

```
设备行为模式 → 情绪状态推断 → MindBloom 标签 → 反思引导
```

### 2.2 情绪类型与行为模式

| 情绪类别 | 行为特征 | 判定逻辑 | MindBloom 标签 |
|---------|---------|---------|---------------|
| 焦虑 | 快速抖动鼠标、高频点击、频繁切换应用 | 鼠标速度>1500px/s 且点击>10 次/分钟 | #焦虑 #紧张 #需要冷静 |
| 疲惫 | 移动缓慢、长时间静止、打字间隔延长 | 鼠标速度<500px/s 且静止>300 秒 | #疲惫 #能量低 #需要休息 |
| 内耗 | 长时间停留在社交媒体、快速滚动、无明确目标 | 社交媒体使用>30 分钟且滚动>50 次 | #内耗 #迷茫 #需要专注 |
| 专注 | 轨迹平稳、输入流畅、长时间无切换 | 无中断>20 分钟且切换<5 次 | #专注 #心流 #保持状态 |
| 压力 | 轨迹抖动、高频点击、错误率高 | 抖动次数>20 且退格键>10 次 | #压力 #需要放松 |
| 平静 | 行为模式平稳、无显著波动 | 各指标波动范围<15% | #平静 #接纳 #感恩 |

## 四、数据采集方案

### 4.1 行为数据采集（无需用户操作）

#### 4.1.1 鼠标事件采集
| 指标 | 采集方式 | 情绪推断 |
|------|---------|---------|
| 点击频率 | 单位时间点击次数 | 高频→焦虑/急躁 |
| 移动速度 | 光标移动速度 | 过快→紧张，过慢→疲惫 |
| 停留时间 | 静止时长 | 长时间→分心/疲惫 |
| 轨迹平滑度 | 移动轨迹抖动程度 | 抖动→压力/不安 |
| 滚动模式 | 滚动频率和幅度 | 快速滚动→焦躁 |

#### 4.1.2 键盘事件采集
| 指标 | 采集方式 | 情绪推断 |
|------|---------|---------|
| 打字速度 | 按键间隔时间 | 过快→焦虑，过慢→犹豫 |
| 错误率 | 退格键使用频率 | 高→压力/分心 |
| 按键持续时间 | 按下到释放时间 | 长→紧张/犹豫 |
| 输入中断 | 无输入间隔 | 频繁→思绪混乱 |

#### 4.1.3 应用使用采集
| 指标 | 采集方式 | 情绪推断 |
|------|---------|---------|
| 切换频率 | 窗口切换次数 | 高频→注意力分散/焦虑 |
| 屏幕时长 | 累计使用时间 | 过长→逃避/内耗 |
| 内容类型 | 应用类别 | 社交媒体→空虚感风险 |

### 4.2 数据冗余采集
```
实时采集 → 内存缓存 → 本地日志文件 → 加密备份
     ↓
   主数据库（SQLite）
```

### 4.3 用户触发标注（可选）

**触发时机：**
- 用户主动点击"记录状态"按钮
- 每周一次定期提醒（可配置关闭）

**问卷内容：**
1. 当前身体感受（1-5 分）
   - 眼睛疲劳
   - 肩膀酸痛
   - 手腕不适
   - 整体疲惫感

2. 当前情绪状态（多选）
   - 焦虑 / 紧张
   - 疲惫 / 无力
   - 烦躁 / 易怒
   - 专注 / 平静

## 五、情绪推断引擎设计

### 5.1 情绪判定逻辑

```python
def infer_emotion(mouse_data, keyboard_data, app_data):
    # 计算各情绪指数
    anxiety_score = (mouse.click_freq * 0.3 + 
                     mouse.velocity * 0.2 + 
                     app.switch_freq * 0.2 +
                     keyboard.error_rate * 0.3)
    
    fatigue_score = (mouse.velocity * 0.4 + 
                     mouse.idle_time * 0.3 + 
                     keyboard.interval * 0.3)
    
    # 判定主要情绪
    if anxiety_score > 0.7:
        return "焦虑"
    elif fatigue_score > 0.6:
        return "疲惫"
    elif app.social_media_time > 0.5:
        return "内耗"
    elif mouse.velocity > 0.8 and keyboard.interval < 0.3:
        return "专注"
    else:
        return "平静"
```

### 5.2 置信度计算

```python
def calculate_confidence(inference_result, user_reports):
    # 如果有用户主动标注，提高置信度
    if user_reports and user_reports.confidence > 0.7:
        return 0.95
    # 否则基于行为特征置信度
    return inference_result.confidence
```

## 七、隐私与数据安全

### 7.1 本地化处理
- 所有数据采集和分析在本地完成
- 无云端上传
- 用户可随时清除所有数据

### 7.2 数据脱敏
- 用户 ID 随机生成
- 应用名称仅记录类别
- 不记录具体内容

### 7.3 用户控制权
- 随时关闭采集
- 随时删除数据
- 随时禁用提醒
